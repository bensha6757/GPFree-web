Demo

A contract, a playbook, and an agent that builds what it needs.

Two minutes. The agent is handed a signed contract and the rules it has to satisfy, works out which experts it needs, builds them, and answers with the sentence that proves each finding. Then a rule changes and it rebuilds.

Public CUAD contract and a synthetic playbook. No customer data. 1 min 55 s, no sound.

What to watch for

The agent is not choosing between models. It is making them.

Nothing in the run was set up in advance. The agent reads the task, decides which experts the job needs, and builds them while you watch.

The part worth waiting for is the end. A rule changes, the expert built on that rule goes stale, and it is rebuilt in seconds. That is the difference between a model you trained once and a model you keep.
